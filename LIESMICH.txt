DERO-Patcher – Dying Light: The Beast
=====================================

Was macht das Tool?
  Spielregeln anpassen: Crafting-Rezepte, Loot, Zerlegen, Händlerpreise und
  globale Werte wie Erfahrung, Todesstrafe, Ausdauer, Heilung, Beast-Modus,
  Reparaturen, Inventarplätze und Stapelgrößen.
  Die Voreinstellung "DERO" macht Wurfmesser günstiger und stärker:
  1 Draht statt 3, 5 Stück statt 2 pro Craft, Kopfschuss x3.

So geht's:
  1. Spiel schließen.
  2. DERO-Patcher.exe doppelklicken. Es öffnet sich ein eigenes Fenster.
     (Falls Windows "Der Computer wurde durch Windows geschützt" zeigt:
      "Weitere Informationen" -> "Trotzdem ausführen". Das kommt, weil die .exe nicht signiert ist.)
  3. Der Spielordner wird normalerweise automatisch gefunden. Sonst fragt das Tool danach:
     den Ordner "Dying Light The Beast" in steamapps\common auswählen.
  4. Werte einstellen (oder eine Voreinstellung wählen) und auf "Patchen" klicken. Fertig.

Beim Spielstart steht dann "Modified game data detected" – das ist normal.

Koop / zusammen spielen:
  Das Spiel lässt nur beitreten, wenn Host und Gast exakt dieselben Spieldaten haben.
  -> Einer stellt die Werte ein, klickt "Teilen" und schickt den Code (DERO2....) an den anderen.
  -> Der andere klickt "Teilen", fügt den Code bei "Code übernehmen" ein und patcht ebenfalls.
  -> Unten rechts steht der "Mod-Code". Der muss bei beiden gleich sein.
  -> Oder beide klicken "Mod entfernen".
  Sonst kommt "Beitritt zum Spiel nicht möglich ... Spieldaten unterschiedlich".
  Tipp: Beide sollten dieselbe Tool-Version haben (steht unten links).

Updates:
  Das Tool schaut beim Start nach, ob es eine neue Version gibt, und zeigt dann oben
  einen Hinweis. Ein Klick auf "Jetzt aktualisieren" lädt sie, prüft sie und startet neu.
  Ohne Internet startet das Tool ganz normal.

Gut zu wissen:
  - Die Originaldateien werden NICHT verändert. Der Mod wird als eigene Datei
    ph_ft\source\dataN.pak (N = 2 bis 7) gespeichert.
  - "Mod entfernen" löscht nur diese Datei -> alles wieder original.
  - Nach einem Spiel-Update zeigt das Tool an, dass der Mod veraltet ist.
    Dann einfach nochmal auf "Patchen" klicken.
  - Wer noch den alten "DERO-WurfPatcher" benutzt hat: Der neue erkennt dessen Mod
    und ersetzt ihn beim ersten Patchen. Den alten kannst du löschen.
  - Werte mit dem Hinweis "ungetestet" wurden noch nicht im Spiel ausprobiert.
  - Quellcode und Neuigkeiten: https://github.com/DERO129media/dl-modding-patcher

DERO-Patcher – Dying Light: The Beast
=====================================

Was macht das Tool?
  Spielregeln anpassen: Crafting-Rezepte, Loot, Zerlegen, Händlerpreise und
  globale Werte wie Erfahrung, Todesstrafe, Ausdauer, Heilung, Beast-Modus,
  Reparaturen, Inventarplätze und Stapelgrößen.
  Die Voreinstellung "DERO" macht Wurfmesser günstiger und stärker:
  1 Draht statt 3, 5 Stück statt 2 pro Craft, Kopfschuss x3.

So geht's:
  1. DERO-Patcher.exe in einen eigenen Ordner legen (z. B. Desktop\DERO-Patcher,
     nicht unter "Programme") und doppelklicken. Es öffnet sich ein eigenes Fenster.
     (Falls Windows "Der Computer wurde durch Windows geschützt" zeigt:
      "Weitere Informationen" -> "Trotzdem ausführen". Das kommt, weil die .exe nicht signiert ist.)
  2. Der Spielordner wird normalerweise automatisch gefunden. Sonst fragt das Tool danach:
     den Ordner "Dying Light The Beast" in steamapps\common auswählen.
  3. Werte einstellen (oder eine Voreinstellung wählen).
  4. Spiel schließen und auf "Patchen" klicken. Fertig.

Beim Spielstart steht dann "Modified game data detected" – das ist normal.

Koop / zusammen spielen:
  Das Spiel lässt nur beitreten, wenn alle exakt dieselben Spieldaten haben.
  -> Einer stellt die Werte ein, klickt "Teilen" und schickt den Code (DERO2....) an die Mitspieler.
  -> Die anderen klicken "Teilen", fügen den Code bei "Code übernehmen" ein und patchen ebenfalls.
  -> Unten rechts steht der "Mod-Code". Der muss bei allen gleich sein.
  -> Oder alle klicken "Mod entfernen".
  Sonst kommt "Beitritt zum Spiel nicht möglich ... Spieldaten unterschiedlich".
  Tipp: Alle sollten dieselbe Tool-Version haben (steht unten links).

Updates:
  Das Tool schaut beim Start nach, ob es eine neue Version gibt, und zeigt dann oben
  einen Hinweis. Ein Klick auf "Jetzt aktualisieren" lädt sie, prüft sie und startet neu.
  Ohne Internet startet das Tool ganz normal.

Gut zu wissen:
  - Die Originaldateien werden NICHT verändert. Der Mod wird als eigene Datei
    ph_ft\source\dataN.pak (N = 2 bis 7) gespeichert.
  - "Mod entfernen" löscht nur diese Datei. Danach lädt das Spiel wieder die Originaldaten.
    Dein Spielstand wird dabei NICHT zurückgesetzt: Was du mit dem Mod gesammelt oder
    gespeichert hast, bleibt. Wer sichergehen will, sichert den Spielstand vorher.
  - Vor jedem Ersetzen oder Entfernen wird die bisherige Mod-Datei gesichert:
    %LOCALAPPDATA%\DERO-Patcher\Sicherungen
  - Mod-Dateien anderer Mods fasst das Tool nie an.
  - Nach einem Spiel-Update zeigt das Tool an, dass der Mod veraltet ist.
    Dann einfach nochmal auf "Patchen" klicken (im Koop alle).
  - Wer noch den alten "DERO-WurfPatcher" benutzt hat: Der neue erkennt dessen Mod
    und ersetzt ihn beim ersten Patchen. Den alten kannst du löschen.
  - Deinstallieren: "Mod entfernen" klicken, dann die .exe löschen.
